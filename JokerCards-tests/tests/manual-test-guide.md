# JokerCards 游戏手动测试指南

本文档提供了JokerCards游戏的手动测试指南，包括黑盒测试、兼容性测试和用户体验测试等无法完全自动化的测试类型。

## 黑盒测试

黑盒测试从用户角度测试游戏功能，不关注内部实现。以下是主要的黑盒测试用例：

### 游戏流程测试

1. **开始游戏测试**

   - 启动游戏，确认主菜单正确显示
   - 点击"开始游戏"按钮，确认游戏场景正确加载
   - 验证初始卡牌发放是否正确（玩家和AI对手各应有10张卡牌）

2. **出牌测试**

   - 尝试将卡牌拖拽到场地区域，确认卡牌正确放置
   - 尝试将卡牌拖拽到已满的场地区域（4张卡牌），确认卡牌返回手牌区域
   - 尝试在一回合内出超过3张卡牌，确认第4张卡牌无法出牌

3. **换牌测试**

   - 尝试将卡牌拖拽到换牌区域，确认卡牌被替换
   - 尝试在换牌次数用完后再次换牌，确认无法换牌

4. **回合结束测试**

   - 点击"结束回合"按钮，确认AI对手出牌
   - 确认分数正确计算并显示
   - 确认新回合正确开始

5. **游戏结束测试**
   - 完成5个回合，确认游戏结束弹窗显示
   - 确认最终分数正确显示
   - 点击"重新开始"按钮，确认游戏重新开始

### 功能测试

1. **卡牌拖拽功能**

   - 测试卡牌拖拽的流畅性
   - 测试卡牌拖拽到不同区域的响应

2. **场景效果功能**

   - 测试每个场景效果是否正确应用
   - 测试场景效果对分数计算的影响

3. **特殊牌型功能**

   - 测试各种特殊牌型（同花顺、四条、葫芦等）是否被正确识别
   - 测试特殊牌型对分数计算的影响

4. **AI对手功能**
   - 测试AI对手是否正确出牌
   - 测试AI对手的卡牌是否正确显示
   - 测试AI对手的分数是否正确计算

## 兼容性测试

兼容性测试确保游戏在不同环境中正常运行。

### 浏览器兼容性测试

在以下浏览器中测试游戏：

1. **Google Chrome**（最新版本）
2. **Mozilla Firefox**（最新版本）
3. **Microsoft Edge**（最新版本）
4. **Safari**（最新版本，如果有Mac设备）

测试内容：

- 游戏是否正常加载
- 图形渲染是否正常
- 交互功能是否正常
- 性能是否流畅

### 设备兼容性测试

在不同设备上测试游戏：

1. **桌面电脑**（Windows、macOS）
2. **笔记本电脑**（不同屏幕分辨率）
3. **平板电脑**（如果支持）
4. **移动设备**（如果支持）

测试内容：

- 游戏界面是否适应不同屏幕尺寸
- 触摸操作是否正常（在支持触摸的设备上）
- 性能是否在不同硬件配置下保持稳定

## 性能测试

手动性能测试关注游戏在实际使用场景中的表现。

### 帧率测试

1. 使用浏览器开发者工具监控帧率
2. 在不同游戏阶段记录帧率：
   - 游戏开始时
   - 出牌过程中
   - AI对手出牌时
   - 多张卡牌同时移动时
   - 游戏结束时

### 内存使用测试

1. 使用浏览器开发者工具监控内存使用
2. 在长时间游戏过程中观察内存使用趋势
3. 检查是否存在内存泄漏

### 加载时间测试

1. 测量游戏初始加载时间
2. 测量场景切换时间
3. 测量资源（如卡牌图像）加载时间

## 用户体验测试

用户体验测试关注游戏的可用性和乐趣。

### 可用性测试

1. **界面清晰度**：测试界面元素是否清晰可见
2. **操作直观性**：测试操作是否符合直觉
3. **反馈及时性**：测试游戏是否提供及时反馈
4. **错误处理**：测试游戏如何处理错误操作

### 游戏体验测试

1. **游戏平衡性**：测试游戏难度是否适中
2. **游戏乐趣**：评估游戏是否有趣
3. **重玩价值**：评估游戏是否有重玩价值

## 测试执行计划

1. 首先执行自动化测试（单元测试、功能测试等）
2. 修复自动化测试发现的问题
3. 执行手动黑盒测试
4. 执行兼容性测试
5. 执行性能测试
6. 执行用户体验测试
7. 汇总测试结果，生成测试报告
8. 根据测试报告修复问题
9. 进行回归测试，确认问题已修复
