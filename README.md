# Joker Cards

一个基于Cocos Creator开发的卡牌游戏，玩家可以通过组合不同的卡牌获得分数。

## 游戏特点

- 多种卡牌组合方式：顺子、同花、对子等
- 场景效果系统：每个场地有不同的特殊效果
- 回合制游戏机制：每局游戏最多5个回合
- 特殊牌型奖励：双偶星、三贤者、四骑士等

## 游戏规则

1. 游戏共有5个回合
2. 每个回合玩家可以打出卡牌到三个不同的场地
3. 每个场地有特殊的场景效果
4. 通过组合卡牌获得分数
5. 回合结束时计算总分

## 开发环境

- Cocos Creator 3.x
- TypeScript

## 安装与运行

1. 克隆仓库

   ```bash
   git clone https://github.com/你的用户名/JokerCards.git
   ```

2. 使用Cocos Creator打开项目

3. 点击"运行"按钮在浏览器中预览游戏

## 项目结构

- `assets/scripts/`: 游戏脚本文件
- `assets/resources/`: 游戏资源文件
- `assets/scenes/`: 游戏场景文件
