字体

标题字体

  • 字体家族: "Arial Bold", sans-serif
  • 大小:
    • 主标题: 48px
    • 副标题: 36px
    • 小标题: 24px
  • 颜色: #FFFFFF (白色) 或 #3A7BDA (主蓝色)
  • 效果:
    • 阴影: 2px 2px 4px rgba(0, 0, 0, 0.5)
    • 可选描边: 1px #0F1E37 (深暗蓝色)

正文字体

  • 字体家族: "Arial", sans-serif
  • 大小:
    • 大文本: 18px
    • 标准文本: 16px
    • 小文本: 14px
  • 颜色: #ECECEC (浅灰色) 或 #FFFFFF (白色)
  • 效果:
    • 轻微阴影: 1px 1px 2px rgba(0, 0, 0, 0.3)

按钮文本

  • 字体家族: "Arial Bold", sans-serif
  • 大小: 20px
  • 颜色: #FFFFFF (白色)
  • 效果:
    • 阴影: 1px 1px 2px rgba(0, 0, 0, 0.5)
    • 全大写

卡牌样式

卡牌基本样式

  • 尺寸: 120px × 180px
  • 圆角: 8px
  • 边框: 2px 白色 (#FFFFFF)
  • 阴影: 0px 4px 8px rgba(0, 0, 0, 0.5)

图标样式

功能图标

  • 尺寸: 32px × 32px (大), 24px × 24px (中), 16px × 16px (小)
  • 颜色: 主要使用白色 (#FFFFFF)
  • 效果:
    • 轻微阴影: 1px 1px 2px rgba(0, 0, 0, 0.3)
    • 悬停时颜色变为强调色 (#E67E22)

状态图标

  • 尺寸: 24px × 24px
  • 颜色: 根据状态使用对应的功能色
  • 效果:
    • 可能有轻微动画效果
    • 重要状态可能有脉动效果

弹窗样式

基本弹窗

  • 背景: 深蓝色 (#1D3C6E) 半透明 (80% 不透明度)
  • 边框: 2px 蓝色 (#3A7BDA)
  • 圆角: 12px
  • 阴影: 0px 8px 16px rgba(0, 0, 0, 0.7)
  • 标题: 居中，使用标题字体
  • 内容: 使用正文字体
  • 按钮: 底部居中或两侧对齐

特殊弹窗

  • 成功弹窗: 使用成功色 (#2ECC71) 作为边框和强调
  • 警告弹窗: 使用警告色 (#F1C40F) 作为边框和强调
  • 错误弹窗: 使用错误色 (#E74C3C) 作为边框和强调

动画效果指南

过渡动画

  • 持续时间: 300ms (快速), 500ms (标准), 800ms (慢速)
  • 缓动函数:
    • 进入: ease-out 或 cubic-bezier(0.0, 0.0, 0.2, 1)
    • 退出: ease-in 或 cubic-bezier(0.4, 0.0, 1, 1)
    • 强调: ease-in-out 或 cubic-bezier(0.4, 0.0, 0.2, 1)

反馈动画

  • 按钮点击: 轻微缩小 (scale: 0.95) 然后恢复
  • 卡牌选择: 上浮 (translateY: -10px) 并轻微放大 (scale: 1.05)
  • 错误提示: 轻微左右摇晃 (translateX: ±5px)
  • 成功提示: 轻微放大 (scale: 1.1) 然后恢复

响应式设计断点

  • 移动设备: < 768px
  • 平板设备: 768px - 1024px
  • 桌面设备: > 1024px

可访问性指南

  • 颜色对比度: 所有文本应至少达到 WCAG AA 级别 (4.5:1)
  • 文本大小: 最小正文文本不应小于 14px
  • 交互元素:
    • 最小触摸区域为 44px × 44px
    • 提供明确的焦点状态
    • 避免仅依赖颜色传达信息
