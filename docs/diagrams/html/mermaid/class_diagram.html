核心类关系图展示了FoolCards游戏中主要类之间的关系：

  • GameManager：游戏的核心管理类，负责游戏逻辑和状态管理
  • Card：卡牌类，表示游戏中的一张卡牌
  • PlayArea：场地类，表示游戏中的一个场地区域
  • SceneEffect：场景效果类，定义不同场景的特殊效果
  • SpecialHands：特殊牌型管理类，检测和处理特殊牌型
  • AIOpponent：AI对手类，处理AI的行为和决策

GameManager 类

classDiagram -playerScore: number -opponentScore: number -areaScores: number[] -currentRound: number -maxRounds: number -playAreas: PlayArea[] -aiOpponent: AIOpponent -specialHands: SpecialHands -gameState: string +init(): void +startGame(): void +startNewRound(): void +endRound(): void +playCard(card: Card, area: PlayArea): void +calculateScore(): number +checkSpecialHands(): void +showGameOver(): void +resetGame(): void }

GameManager 是游戏的核心管理类，负责：

  • 管理玩家分数、回合数和游戏区域
  • 控制游戏流程（开始新回合、结束回合等）
  • 处理卡牌的打出和分数计算
  • 检测特殊牌型和应用场地效果
  • 控制AI对手的行为
  • 显示游戏结果
