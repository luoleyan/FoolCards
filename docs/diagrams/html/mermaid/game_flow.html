主要游戏流程展示了FoolCards游戏从启动到结束的完整流程：

  1. 游戏启动后首先加载必要的资源
  2. 资源加载完成后显示主菜单
  3. 玩家选择开始新游戏
  4. 进入游戏循环（包含多个回合）
  5. 游戏结束后显示结果
  6. 玩家可以选择返回主菜单

游戏循环详细流程展示了一个完整游戏中的回合循环：

  1. 开始新回合，重置回合状态
  2. 向玩家和AI对手发放卡牌
  3. 玩家进行回合操作
  4. 回合结束后计算分数
  5. 检查游戏是否结束（达到5回合）
  6. 如果游戏未结束，开始新回合；否则结束游戏

玩家回合详细流程展示了玩家在一个回合中的操作流程：

  1. 玩家从手牌中选择一张卡牌
  2. 选择要放置卡牌的场地
  3. 确认选择并打出卡牌
  4. 系统检查是否形成特殊牌型
  5. 应用场地效果
  6. 计算临时分数
  7. 玩家可以选择继续出牌或结束回合
  8. 玩家结束回合后，AI对手进行回合操作
  9. AI对手回合结束后，当前回合结束

分数计算流程展示了游戏中分数的计算方式：

  1. 计算基础分数：卡牌点数之和
  2. 检查是否形成特殊牌型（如对子、顺子等）
  3. 计算特殊牌型带来的额外分数
  4. 应用场地效果（如花色奖励、点数奖励等）
  5. 计算场地效果带来的额外分数
  6. 汇总所有分数：基础分数 + 特殊牌型加分 + 场地效果加分
  7. 更新玩家的总分数
