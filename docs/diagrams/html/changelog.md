# FoolCards 项目分析文档更新日志

本文档记录FoolCards项目分析文档的重要更新和变更。

## 2023年12月更新

### 添加图表交互功能 (2023-12-10)

- 新增点击图表查看大图功能
  - 用户可以点击任何Mermaid图表在模态框中查看大图
  - 大图模式下支持放大、缩小和重置操作
  - 可通过关闭按钮、点击外部区域或ESC键关闭大图

- 新增保存图表为图片功能
  - 在大图模式下可通过右下角按钮保存图表为PNG图片
  - 支持右键菜单，提供保存图片、放大、缩小和重置缩放选项
  - 保存的图片文件名根据图表标题自动生成

- 技术改进
  - 添加html2canvas库支持，用于将SVG图表转换为PNG图片
  - 添加右键菜单功能，提升用户体验
  - 优化图表交互提示，增加悬停效果

### 修复侧边栏链接问题 (2023-12-05)

- 修复所有子页面侧边栏链接导致404错误的问题
  - 更新结构图子页面的侧边栏链接
  - 更新ER图子页面的侧边栏链接
  - 更新流程图子页面的侧边栏链接
  - 更新UI设计图子页面的侧边栏链接

- 技术改进
  - 使用更明确的相对路径，确保链接在不同目录层级下正常工作
  - 统一所有页面的链接格式，提高可维护性

## 2023年11月更新

### 初始版本发布 (2023-11-15)

- 基础功能实现
  - Markdown文档转换为HTML静态网页
  - ASCII图表转换为交互式Mermaid图表
  - 代码高亮显示
  - 响应式设计，适应不同屏幕尺寸
  - 分类展示不同类型的文档

- 文档结构
  - 结构图文档：项目结构、类图、组件交互等
  - ER图文档：数据模型和实体关系
  - 流程图文档：游戏流程、状态转换等
  - UI设计图文档：界面布局、交互流程等

- 技术栈
  - 使用Marked.js解析Markdown
  - 使用Mermaid.js生成图表
  - 使用Highlight.js实现代码高亮
