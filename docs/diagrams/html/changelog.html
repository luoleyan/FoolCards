FoolCards 更新日志

本文档记录FoolCards项目的主要更新和变更。

2023年12月更新

文档功能增强

添加图表交互功能 (2023-12-10)

新增功能：

  • 点击图表查看大图：
    • 用户可以点击任何Mermaid图表在模态框中查看大图
    • 大图模式下支持放大、缩小和重置操作
    • 可通过关闭按钮、点击外部区域或ESC键关闭大图
  • 保存图表为图片：
    • 在大图模式下可通过右下角按钮保存图表为PNG图片
    • 支持右键菜单，提供保存图片、放大、缩小和重置缩放选项
    • 保存的图片文件名根据图表标题自动生成

技术改进：

  • 添加html2canvas库支持，用于将SVG图表转换为PNG图片
  • 添加右键菜单功能，提升用户体验
  • 优化图表交互提示，增加悬停效果

受影响文件：

  • docs/diagrams/html/css/modal.css (新增)
  • docs/diagrams/html/js/diagram-modal.js (新增)
  • 所有HTML文档页面 (更新)

修复侧边栏链接问题 (2023-12-05)

问题描述：

在子页面中点击侧边栏链接时，会出现404错误。这是因为相对路径解析问题，导致URL中出现重复的目录路径。

修复内容：

  • 更新结构图子页面的侧边栏链接
  • 更新ER图子页面的侧边栏链接
  • 更新流程图子页面的侧边栏链接
  • 更新UI设计图子页面的侧边栏链接

技术改进：

  • 使用更明确的相对路径，确保链接在不同目录层级下正常工作
  • 统一所有页面的链接格式，提高可维护性

2023年11月更新

错误修复

AI对手卡牌显示错误修复

问题描述：

在AI对手出牌过程中，当卡牌显示时偶尔会出现"Cannot read properties of null (reading 'getComponent')"错误。这个问题发生在异步加载卡牌精灵的过程中，当节点在加载完成前被销毁时。

修复内容：

  1. 在AIOpponent.ts中添加了全面的节点有效性检查
  2. 改进了异步操作中的错误处理
  3. 添加了try-catch块来捕获组件操作中的异常
  4. 在Promise链的每个步骤中添加了额外的安全检查

受影响文件：

  • assets/scripts/AIOpponent.ts
  • assets/scripts/Card.ts

技术细节：

  • 添加了对节点和组件有效性的全面检查
  • 在异步操作的每个步骤中验证节点状态
  • 添加了try-catch块来捕获组件操作中的异常
  • 改进了错误日志，提供更详细的信息
  • 在Promise链的每个步骤中添加了额外的安全检查
  • 确保在节点无效时优雅地终止操作
  • 添加了对组件创建过程的验证
