关于项目

FoolCards是一款基于Cocos Creator开发的卡牌游戏，玩家可以通过组合不同的卡牌获得分数。游戏具有多种卡牌组合方式、场景效果系统、回合制游戏机制和特殊牌型奖励等特点。

项目使用TypeScript语言开发，基于组件化设计思想，实现了高度模块化和可扩展的架构。
