## 详细元素说明

### 1. 玩家手牌区域
- **位置**: 屏幕底部
- **内容**: 显示玩家当前持有的卡牌（正面朝上）
- **交互**: 可点击选择卡牌
- **布局**: 水平排列，略微重叠，选中时上浮
- **视觉效果**: 卡牌有光晕效果，选中时边缘高亮

### 2. 对手手牌区域
- **位置**: 屏幕顶部左侧
- **内容**: 显示对手持有的卡牌数量（背面朝上）
- **交互**: 无交互
- **布局**: 水平排列，重叠显示
- **视觉效果**: 卡牌背面设计，数量指示器

### 3. 场地区域 (1-3)
- **位置**: 屏幕中央，水平排列
- **内容**: 
  - 场地背景
  - 场地效果图标
  - 已放置的卡牌
  - 当前分数
- **交互**: 可点击选择放置卡牌
- **布局**: 网格布局，最多容纳3张卡牌
- **视觉效果**: 
  - 可放置时边缘高亮
  - 场地效果图标在左上角
  - 分数显示在底部

### 4. 换牌区域
- **位置**: 屏幕左下角
- **内容**: 
  - 换牌按钮
  - 剩余换牌次数
- **交互**: 点击进入换牌模式
- **视觉效果**: 
  - 按钮样式与游戏风格一致
  - 剩余次数显示为数字

### 5. 计时器
- **位置**: 屏幕右下角
- **内容**: 当前回合剩余时间
- **交互**: 无交互
- **视觉效果**: 
  - 倒计时数字
  - 时间不足时闪烁警告

### 6. 结束回合按钮
- **位置**: 屏幕右下角，计时器下方
- **内容**: "结束回合"文本
- **交互**: 点击结束当前回合
- **视觉效果**: 
  - 突出的按钮样式
  - 点击时有按压效果

### 7. 回合信息
- **位置**: 屏幕顶部右侧
- **内容**: 
  - 当前回合数
  - 总回合数
  - 玩家分数
- **交互**: 无交互
- **视觉效果**: 
  - 清晰的文本显示
  - 分数变化时有动画效果

## 响应式设计考虑

- **桌面端**:
  - 全屏显示所有元素
  - 鼠标悬停效果
  - 键盘快捷键支持

- **移动端**:
  - 手牌区域可滚动
  - 更大的触摸区域
  - 简化的UI元素
  - 竖屏适配布局调整

- **平板端**:
  - 介于桌面和移动端之间的布局
  - 优化触摸交互
  - 保留完整功能
