## UI元素说明

1. **玩家手牌区域**：
   - 位置：屏幕底部中央
   - 功能：显示玩家当前持有的卡牌
   - 交互：点击选择卡牌

2. **对手手牌区域**：
   - 位置：屏幕顶部中央
   - 功能：显示对手持有的卡牌数量（背面朝上）
   - 交互：无

3. **场地区域(1-3)**：
   - 位置：屏幕中央，水平排列
   - 功能：显示已打出的卡牌和场地效果
   - 交互：点击选择要放置卡牌的场地

4. **换牌区域**：
   - 位置：屏幕左下角
   - 功能：允许玩家更换手牌
   - 交互：点击进行换牌操作

5. **计时器**：
   - 位置：屏幕右下角
   - 功能：显示当前回合剩余时间
   - 交互：无

6. **结束回合按钮**：
   - 位置：屏幕右下角，计时器下方
   - 功能：手动结束当前回合
   - 交互：点击结束回合

## 响应式设计考虑

- 所有UI元素应根据屏幕尺寸进行适当缩放
- 在小屏幕设备上，手牌区域可能需要滚动功能
- 场地区域的大小应保持一致，并在不同屏幕尺寸下保持适当比例
- 按钮和交互元素的触摸区域应足够大，以确保良好的移动设备体验
