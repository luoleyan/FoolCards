# FoolCards 游戏界面交互流程图

## 游戏主流程交互

```
+----------------+     +----------------+     +----------------+
|                |     |                |     |                |
|  启动游戏       |---->|  主菜单界面     |---->|  点击开始游戏  |
|                |     |                |     |                |
+----------------+     +----------------+     +-------+--------+
                                                     |
                                                     v
+----------------+     +----------------+     +----------------+
|                |     |                |     |                |
|  游戏主界面     |<----|  资源加载完成   |<----|  加载界面      |
|                |     |                |     |                |
+-------+--------+     +----------------+     +----------------+
        |
        | 游戏循环
        v
+----------------+     +----------------+     +----------------+
|                |     |                |     |                |
|  游戏结束       |---->|  显示结果弹窗   |---->|  选择后续操作  |
|                |     |                |     |                |
+----------------+     +----------------+     +-------+--------+
                                                     |
                       +----------------+            |
                       |                |            |
                       |  返回主菜单     |<-----------+
                       |                |            |
                       +----------------+            |
                                                     |
                       +----------------+            |
                       |                |            |
                       |  再玩一局      |<-----------+
                       |                |
                       +----------------+
```

## 玩家回合交互流程

```
+----------------+     +----------------+     +----------------+
|                |     |                |     |                |
|  回合开始      |---->|  玩家操作阶段   |---->|  选择卡牌      |
|                |     |                |     |                |
+----------------+     +----------------+     +-------+--------+
                                                     |
        ^                                            |
        |                                            v
+----------------+     +----------------+     +----------------+
|                |     |                |     |                |
|  回合结束      |<----|  点击结束回合   |<----|  选择场地      |
|                |     |  按钮          |     |                |
+----------------+     +----------------+     +-------+--------+
                               ^                      |
                               |                      |
                               |                      v
                       +----------------+     +----------------+
                       |                |     |                |
                       |  计算得分      |<----|  卡牌放置      |
                       |                |     |                |
                       +----------------+     +----------------+
                               |
                               |
                               v
                       +----------------+     +----------------+
                       |                |     |                |
                       |  检查特殊牌型   |---->| 显示特殊牌型   |
                       |                |     | 弹窗 (如有)    |
                       +----------------+     +----------------+
```

## 换牌操作交互流程

```
+----------------+     +----------------+     +----------------+

|  点击换牌区域   |---->|  进入换牌模式   |---->|  选择要换的卡牌 |
|                |     |                |     |                |
+----------------+     +----------------+     +-------+--------+
                                                     |
                                                     v

|                |     |                |     |                |
|  返回正常模式   |<----|  换牌完成      |<----|  确认换牌      |
|                |     |                |     |                |
+----------------+     +----------------+     +----------------+
```

## 特殊牌型检测交互流程

```
+----------------+     +----------------+     +----------------+
|                |     |                |     |                |
|  卡牌放置完成   |---->|  检测特殊牌型   |---->|  无特殊牌型    |
|                |     |                |     |                |
+----------------+     +-------+--------+     +----------------+
                               |
                               |
                               v
                       +----------------+     +----------------+
                       |                |     |                |
                       |  发现特殊牌型   |---->|  显示特殊牌型   |
                       |                |     |  弹窗          |
                       +----------------+     +-------+--------+
                                                     |
                                                     v
                                              +----------------+
                                              |                |
                                              |  应用特殊牌型   |
                                              |  效果和加分    |
                                              +----------------+
```

## 游戏结束交互流程

```
+----------------+     +----------------+     +----------------+
|                |     |                |     |                |
|  最后回合结束   |---->|  计算最终得分   |---->|  显示游戏结束  |
|                |     |                |     |  弹窗          |
+----------------+     +----------------+     +-------+--------+
                                                     |
                       +----------------+            |
                       |                |            |
                       |  点击"返回     |<-----------+
                       |  主菜单"按钮   |            |
                       +-------+--------+            |
                               |                     |
                               v                     |
                       +----------------+            |
                       |                |            |
                       |  返回主菜单     |            |
                       |  界面          |            |
                       +----------------+            |
                                                     |
                       +----------------+            |
                       |                |            |
                       |  点击"再玩     |<-----------+
                       |  一局"按钮     |
                       +-------+--------+
                               |
                               v
                       +----------------+
                       |                |
                       |  重置游戏状态   |
                       |  开始新游戏    |
                       +----------------+
```

## 设置菜单交互流程

```
+----------------+     +----------------+     +----------------+
|                |     |                |     |                |
|  点击设置按钮   |---->|  显示设置弹窗   |---->|  调整设置选项  |
|                |     |                |     |                |
+----------------+     +----------------+     +-------+--------+
                                                     |
                       +----------------+            |
                       |                |            |
                       |  点击"取消"    |<-----------+
                       |  按钮          |            |
                       +-------+--------+            |
                               |                     |
                               v                     |
                       +----------------+            |
                       |                |            |
                       |  关闭设置弹窗   |            |
                       |  不保存更改    |            |
                       +----------------+            |
                                                     |
                       +----------------+            |
                       |                |            |
                       |  点击"确认"    |<-----------+
                       |  按钮          |
                       +-------+--------+
                               |
                               v
                       +----------------+
                       |                |
                       |  保存设置更改   |
                       |  关闭设置弹窗   |
                       +----------------+
```

```
|  屏幕          |     |                |     |                |
+----------------+     +----------------+     +-------+--------+
                                                     |
                                                     v

                                              |                |
                                              +-------+--------+
                                                     |
                       +----------------+            |
                       |                |            |
                       |  视觉反馈      |<-----------+
                       |  (高亮/动画)   |            |
                       +-------+--------+            |
                               |                     |
                               v                     |
                       +----------------+            |
                       |                |            |
                       |  音效反馈      |<-----------+
                       |                |
                       +----------------+
```

## 拖拽操作流程 (可选实现)

```
+----------------+     +----------------+     +----------------+
|                |     |                |     |                |
|  按下卡牌       |---->|  开始拖拽      |---->|  移动卡牌      |

                                                     |
                       +----------------+            |
                       |                |            |
                       |  放置无效      |<-----------+

                       +-------+--------+            |
                               |                     |
                               v                     |
                       +----------------+            |
                       |                |            |
                       |  卡牌返回      |            |
                       |  原位置        |            |
                       +----------------+            |
                                                     |
                       +----------------+            |
                       |                |            |
                       |  放置有效      |<-----------+
                       |  (有效区域)    |
                       +-------+--------+
                               |
                               v
                       +----------------+
                       |                |
                       |  卡牌放置到    |
                       |  目标位置      |
                       +----------------+
```

## 错误处理流程

```
+----------------+     +----------------+     +----------------+
|                |     |                |     |                |
|  用户操作      |---->|  验证操作      |---->|  操作有效      |
|                |     |                |     |                |
+----------------+     +-------+--------+     +----------------+
                               |                      |
                               |                      |
                               v                      v
                       +----------------+     +----------------+
                       |                |     |                |
                       |  操作无效      |     |  执行操作      |
                       |                |     |                |
                       +-------+--------+     +----------------+
                               |
                               |
                               v
                       +----------------+     +----------------+
                       |                |     |                |
                       |  显示错误提示  |---->|  错误动画      |
                       |                |     |  (震动/闪烁)   |
                       +----------------+     +----------------+
```
