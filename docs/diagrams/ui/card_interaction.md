## 卡牌视觉状态

1. **普通状态**：
   - 卡牌处于手牌中的默认状态
   - 无特殊视觉效果

2. **选中状态**：
   - 卡牌被玩家选中
   - 视觉效果：轻微上浮、边缘高亮

3. **不可用状态**：
   - 卡牌当前不可选择或使用
   - 视觉效果：灰色滤镜、透明度降低

4. **打出状态**：
   - 卡牌已被打出到场地
   - 视觉效果：根据场地可能有特殊效果（如光晕、粒子效果等）

## 卡牌动画效果

1. **发牌动画**：
   - 从牌堆到玩家手牌的移动动画
   - 包含轻微的弹跳和旋转效果

2. **选择动画**：
   - 卡牌被选中时的上浮和放大效果
   - 边缘高亮闪烁

3. **打出动画**：
   - 从手牌到场地的飞行动画
   - 可能包含轨迹效果或残影

4. **特殊牌型动画**：
   - 形成特殊牌型时的组合动画
   - 可能包含粒子效果、闪光或特殊符号

5. **换牌动画**：
   - 旧卡牌淡出，新卡牌淡入
   - 包含翻转或滑动效果

## 触摸反馈

1. **点击反馈**：
   - 轻微的缩放效果
   - 可能伴随短暂的音效

2. **拖拽反馈**：
   - 卡牌跟随手指移动
   - 可能显示可放置区域的高亮提示

3. **错误操作反馈**：
   - 卡牌轻微震动
   - 可能显示错误提示文本或图标

4. **成功操作反馈**：
   - 愉悦的动画效果
   - 可能伴随成功音效或粒子效果
