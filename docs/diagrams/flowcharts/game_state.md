## 状态转换触发条件

1. **初始状态 → 加载状态**：
   - 游戏启动

2. **加载状态 → 主菜单状态**：
   - 资源加载完成

3. **主菜单状态 → 游戏准备**：
   - 玩家点击"开始游戏"按钮

4. **游戏准备 → 游戏中**：
   - 游戏初始化完成
   - 卡牌发放完成

5. **游戏中 → 游戏结束**：
   - 达到最大回合数（5回合）

6. **游戏结束 → 结算状态**：
   - 显示游戏结果

7. **结算状态 → 游戏中**：
   - 玩家选择"再来一局"

8. **结算状态 → 主菜单状态**：
   - 玩家选择"返回主菜单"

## 状态持久化

游戏在以下状态转换点进行数据持久化：

1. **回合结束时**：
   - 保存当前回合分数
   - 更新总分数

2. **游戏结束时**：
   - 保存游戏结果
   - 更新历史记录（如果有）

3. **设置更改时**：
   - 保存用户设置
