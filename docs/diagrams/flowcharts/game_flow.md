## 游戏结束条件

1. 达到最大回合数（5回合）

## 分数计算

1. 基础分数：卡牌点数之和
2. 特殊牌型加分：根据特殊牌型（如对子、顺子等）获得额外分数
3. 场地效果加分：根据场地效果（如花色奖励、点数奖励等）获得额外分数
4. 最终分数 = 基础分数 + 特殊牌型加分 + 场地效果加分
